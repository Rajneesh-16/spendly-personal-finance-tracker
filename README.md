# Spendly – Personal Finance Tracker

Spendly is a modern, responsive personal finance tracker built using HTML, CSS, and vanilla JavaScript.

It helps users track their income and expenses, manage budgets, set savings goals, and visualize their financial activity through interactive charts.

## 🚀 Live Demo

[View Spendly Live](YOUR_GITHUB_PAGES_URL)

## ✨ Features

- 📊 Financial dashboard
- 💰 Income and expense tracking
- 🧾 Transaction management
- 📅 Monthly budgets
- 🎯 Savings goals
- 📈 Financial analytics and charts
- 🔎 Search, filtering, and sorting
- 🌙 Dark mode
- 💱 Multiple currency options
- 📱 Responsive design
- 💾 LocalStorage-based data persistence
- 📤 Export financial data as JSON
- 📥 Import financial data from JSON
- 🔔 Financial insights and notifications
- 🎨 Modern fintech SaaS interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Chart.js
- Browser LocalStorage
- Google Fonts
- Font Awesome / Icons
